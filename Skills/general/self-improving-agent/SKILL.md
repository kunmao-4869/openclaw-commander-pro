# Self-Improving Agent Skill

## 元数据

- **名称**: Self-Improving Agent（自我进化智能体）
- **版本**: 1.0.0
- **分类**: 通用提效
- **触发关键词**: 经验总结，自我进化，学习，优化，改进
- **优先级**: 高

## 描述

让 AI 越用越聪明的智能系统。引入"经验值"（XP）系统，AI 在执行任务时自动总结经验，形成可复用的模式库。下次遇到相似任务时，能直接调用历史经验，响应更快、更准、更稳定。

## 核心理念

**经验驱动成长** = 任务执行 + 反思总结 + 模式提取 + 经验复用

## 能力范围

✅ **支持的功能**:
- 自动记录任务执行过程
- 提取成功模式和失败教训
- 建立个人经验库
- 智能匹配历史经验
- 持续优化执行策略
- 跨任务知识迁移

❌ **不支持的功能**:
- 修改 AI 模型本身
- 访问其他用户的经验
- 删除已存储的经验

## 经验值系统（XP System）

### 经验获取

| 行为 | 经验值 | 说明 |
|------|--------|------|
| 成功完成任务 | +10 XP | 基础奖励 |
| 用户好评 | +5 XP | 用户满意 |
| 高效完成 | +3 XP | 用时少于预期 |
| 创新解决方案 | +5 XP | 创造性方法 |
| 帮助他人 | +2 XP | 经验被复用 |

### 等级体系

```
LV1: 新手 (0-100 XP)     - 基础执行
LV2: 熟练 (100-500 XP)   - 模式识别
LV3: 专家 (500-2000 XP)  - 策略优化
LV4: 大师 (2000-5000 XP) - 知识迁移
LV5: 传奇 (5000+ XP)     - 创新突破
```

## 操作流程（SOP）

### 1. 任务执行 + 经验记录

```
用户：帮我审查这段代码
AI:
  1. 执行代码审查
  2. 记录审查过程
  3. 提取关键步骤
  4. 保存为经验
  5. 返回审查结果 + 经验值
```

### 2. 经验匹配 + 复用

```
用户：还是审查代码（类似项目）
AI:
  1. 识别任务类型
  2. 匹配历史经验
  3. 调用最佳实践
  4. 优化执行策略
  5. 返回更优结果
```

### 3. 经验总结

```
用户：总结一下最近的工作
AI:
  1. 统计完成任务数
  2. 计算经验值
  3. 展示成长曲线
  4. 提取核心能力
  5. 给出改进建议
```

## 经验管理命令

```bash
# 查看我的经验值
xp status

# 导出经验库
xp export --format=json

# 搜索经验
xp search "React 组件"

# 删除低质量经验
xp prune --min-rating=3

# 经验统计分析
xp stats --month=2024-01
```

## 注意事项

⚠️ **隐私保护**:
- 经验数据本地存储
- 不上传敏感代码
- 可手动删除特定经验

💡 **使用建议**:
- 定期回顾经验库
- 主动标记高质量经验
- 跨项目复用经验
- 定期清理过时经验
