# Humanizer-zh Skill

## 元数据

- **名称**: Humanizer-zh（中文人性化）
- **版本**: 1.0.0
- **分类**: 通用提效
- **触发关键词**: 去 AI 味，人性化，自然语言，润色，改写
- **优先级**: 高

## 描述

去"AI 味"神器，能把 AI 生成的生硬表达替换成更接地气、符合人类习惯的自然语言。内置中文表达习惯词库，自动识别并替换"此外"、"综上所述"、"值得注意的是"等 AI 常用但生硬的表达方式。

## 能力范围

✅ **支持的操作**:
- 识别 AI 生成的生硬表达
- 替换为自然的人类语言
- 保持原意不变
- 适配不同文体（正式/非正式）
- 公众号/小红书风格优化
- 技术文档口语化

❌ **不支持的操作**:
- 改变文章核心内容
- 翻译其他语言
- 生成原创内容

## 使用场景

1. **公众号文章**: 让 AI 生成的文章更像人工撰写
2. **小红书文案**: 添加语气词、表情符号，更接地气
3. **项目文档**: 保持专业的同时更自然
4. **邮件沟通**: 避免生硬的 AI 语气
5. **社交媒体**: 符合平台语言风格

## AI 味词汇对照表

| AI 常用表达 | 人性化替换 |
|------------|-----------|
| 此外 | 另外 / 还有 / 再加上 |
| 综上所述 | 总的来说 / 简单说 / 一句话 |
| 值得注意的是 | 要注意 / 重点是 / 特别提醒 |
| 基于上述分析 | 看了这些 / 分析完 |
| 可以得出结论 | 所以 / 看来 / 这么看 |
| 首先...其次...最后 | 第一...第二...最后 / 先...再...最后 |
| 然而 | 但是 / 不过 / 话说回来 |
| 因此 | 所以 / 这样一来 / 结果就是 |
| 具体而言 | 具体来说 / 详细说 / 举个例子 |
| 换言之 | 也就是说 / 简单说 / 换个说法 |

## 操作流程（SOP）

### 1. 文本润色

```
用户：帮我去掉这段话的 AI 味
AI:
  1. 分析文本，识别 AI 常用表达
  2. 逐句替换为自然表达
  3. 调整语序和连接词
  4. 返回润色后的文本
```

### 2. 风格转换

```
用户：把这段改成小红书风格
AI:
  1. 识别内容主题
  2. 添加语气词（呀、呢、啦）
  3. 插入合适的表情符号
  4. 调整句式更口语化
  5. 添加热门标签
```

### 3. 正式文档优化

```
用户：让这段技术文档更自然
AI:
  1. 保持专业性
  2. 替换生硬连接词
  3. 简化复杂句式
  4. 添加过渡语
```

## 参数规范

```json
{
  "text": "待处理的文本",
  "style": "casual|formal|social-media|xiaohongshu|wechat",
  "intensity": "light|medium|strong",
  "preserveTerms": ["专业术语 1", "专业术语 2"]
}
```

## 风格选项

- **casual**: 日常口语，轻松自然
- **formal**: 正式文档，专业但自然
- **social-media**: 社交媒体风格
- **xiaohongshu**: 小红书风格（语气词 + 表情）
- **wechat**: 公众号风格（深度但易读）

## 示例对话

**用户**: 帮我去掉这段话的 AI 味：
"综上所述，本项目具有显著的市场优势。值得注意的是，我们的技术方案领先业界。因此，投资建议为强烈推荐。"

**AI**: 已优化，去掉 AI 味后的版本：

"总的来说，这个项目在市场上很有竞争力。特别要说的是，我们的技术比同行都要先进。所以，我强烈建议投资。"

---

**改写说明**:
- "综上所述" → "总的来说"
- "值得注意的是" → "特别要说的是"
- "具有显著优势" → "很有竞争力"
- "领先业界" → "比同行都要先进"
- "因此" → "所以"
- "投资建议为强烈推荐" → "我强烈建议投资"

**用户**: 把这段改成小红书风格

**AI**: 小红书风格版本来啦～ ✨

"宝子们！今天必须跟你们分享一个超棒的项目！💖

说真的，这个项目在市场上真的太能打了好吗！🔥 特别是他们的技术，甩同行好几条街～ 🚀

总之就是一句话：投它！冲鸭！💪💰

#项目推荐 #投资 #搞钱 #创业"

---

**改写说明**:
- 添加称呼"宝子们"
- 使用语气词"啦"、"好吗"、"真的"
- 添加表情符号增强情感
- 使用网络流行语"太能打"、"甩几条街"、"冲鸭"
- 添加相关标签

## 注意事项

⚠️ **使用建议**:
- 专业术语会保留，不强行替换
- 过度润色可能改变原意，建议适度
- 某些正式场合（法律、医疗）不建议使用

💡 **最佳实践**:
- 先轻度润色，不满意再加强
- 重要文档人工复核一次
- 结合具体场景选择合适风格

- ✅ 减少生硬感
