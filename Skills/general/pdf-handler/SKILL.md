# PDF Handler Skill

## 元数据

- **名称**: PDF Handler
- **版本**: 1.0.0
- **分类**: 通用提效
- **触发关键词**: PDF, 文档处理，读取 PDF, 合并 PDF, 拆分 PDF, OCR
- **优先级**: 高

## 描述

文档处理神器，支持读取、合并、拆分、OCR 识别甚至填写 PDF 表单。让你在处理文档时无需频繁切换软件，直接在对话中完成所有 PDF 操作。

## 能力范围

✅ **支持的操作**:
- 读取 PDF 内容并提取文本
- 合并多个 PDF 文件
- 拆分 PDF 为多个文件
- OCR 识别扫描版 PDF
- 填写 PDF 表单
- 提取 PDF 中的图片
- 转换 PDF 为其他格式（Word、图片等）

❌ **不支持的操作**:
- 编辑 PDF 内容（需要专业 PDF 编辑器）
- 加密/解密 PDF（涉及安全限制）

## 使用场景

1. **快速阅读**: 上传 PDF，让 AI 总结内容
2. **文档合并**: 将多个报告合并为一个 PDF
3. **内容提取**: 从 PDF 中提取特定章节或数据
4. **表单填写**: 自动填写重复性 PDF 表格
5. **OCR 识别**: 识别扫描版文档内容

## 操作流程（SOP）

### 1. 读取 PDF

```
用户：帮我读取这个 PDF 文件
AI: 
  1. 确认文件路径
  2. 使用 pdf-reader 脚本读取内容
  3. 提取文本并总结
  4. 返回关键信息
```

### 2. 合并 PDF

```
用户：把这些 PDF 合并成一个
AI:
  1. 收集所有 PDF 文件路径
  2. 确认合并顺序
  3. 使用 pdf-merge 脚本合并
  4. 保存到新位置并返回路径
```

### 3. OCR 识别

```
用户：识别这个扫描版 PDF
AI:
  1. 检查文件是否为扫描版
  2. 使用 ocr-script 进行识别
  3. 提取识别结果
  4. 返回可编辑文本
```

## 参数规范

```json
{
  "operation": "read|merge|split|ocr|fill-form",
  "files": ["file1.pdf", "file2.pdf"],
  "output": "output.pdf",
  "options": {
    "pages": "1-10",
    "quality": "high",
    "language": "zh-CN"
  }
}
```

## 注意事项

⚠️ **安全提醒**:
- 不处理包含敏感信息的 PDF
- 大文件（>100MB）需要分批处理
- OCR 识别准确率约 95%，复杂排版可能出错

💡 **最佳实践**:
- 清晰的 PDF 扫描质量更好
- 文字版 PDF 直接提取，无需 OCR
- 合并前确认文件顺序
