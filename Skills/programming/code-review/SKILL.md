# Code Review Skill

## 元数据

- **名称**: Code Review（代码审查）
- **版本**: 1.0.0
- **分类**: 编程开发
- **触发关键词**: 代码审查，Code Review, 代码质量，审查代码
- **优先级**: 高

## 描述

代码质量守护神。可以同时派多个子 Agent 并行审查代码的质量、安全性和性能，并给出置信度评分。非常适合赶项目时快速做代码审核。

## 审查维度

### 🔍 五维审查模型

1. **功能正确性** (30%)
   - 逻辑是否正确
   - 边界条件处理
   - 错误处理完善

2. **代码质量** (25%)
   - 可读性
   - 可维护性
   - 代码规范

3. **性能** (20%)
   - 时间复杂度
   - 空间复杂度
   - 资源使用

4. **安全性** (15%)
   - 输入验证
   - 权限控制
   - 常见漏洞

5. **测试覆盖** (10%)
   - 单元测试
   - 集成测试
   - 测试用例

## 审查流程

```
1. 代码解析 → 2. 多维度分析 → 3. 问题识别 → 4. 建议生成 → 5. 评分报告
```

## 输出格式

```markdown
## Code Review 报告

### 综合评分：⭐⭐⭐⭐ (4.2/5.0)

### ✅ 优点
- 代码结构清晰
- 命名规范
- 注释充分

### ⚠️ 需要改进

#### 🔴 严重 (2 个)
1. SQL 注入风险 - 第 45 行
2. 未验证用户输入 - 第 78 行

#### 🟡 建议 (5 个)
1. 提取重复代码为函数
2. 添加错误处理
3. 优化循环性能

### 📊 详细评分
| 维度 | 评分 | 说明 |
|------|------|------|
| 功能 | 4.5 | 逻辑正确，边界处理好 |
| 质量 | 4.0 | 代码清晰，有小问题 |
| 性能 | 3.5 | 有优化空间 |
| 安全 | 3.0 | 需要加强验证 |
| 测试 | 4.0 | 覆盖良好 |
```
