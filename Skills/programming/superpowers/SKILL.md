# Superpowers Skill

## 元数据

- **名称**: Superpowers（超级能力）
- **版本**: 2.0.0
- **分类**: 编程开发
- **触发关键词**: 开发全流程，项目规划，代码审查，最佳实践，方法论
- **优先级**: 极高

## 描述

社区极火的一整套开发方法论。覆盖从项目规划、代码编写到 Code Review 的全流程，相当于给 AI 加了一套"开发全流程 Buff"。内置经过验证的开发规范和最佳实践，能省下大量梳理时间，让 AI 像资深架构师一样思考和工作。

## 核心理念

**Superpowers = 规范流程 + 最佳实践 + 自动化工具 + 持续改进**

## 能力范围

✅ **支持的场景**:
- 项目启动规划
- 技术选型建议
- 架构设计评审
- 代码规范制定
- 开发流程优化
- Code Review 标准
- 测试策略规划
- 部署流程设计
- 文档规范制定

❌ **不支持的场景**:
- 替代人类决策
- 违反团队现有规范
- 未经实践验证的理论

## 核心原则

### 1. KISS 原则 (Keep It Simple, Stupid)
- 简单优于复杂
- 明确优于隐晦
- 直接优于间接

### 2. DRY 原则 (Don't Repeat Yourself)
- 避免重复代码
- 提取公共逻辑
- 单一数据源

### 3. SOLID 原则
- 单一职责
- 开闭原则
- 里氏替换
- 接口隔离
- 依赖倒置

### 4. YAGNI 原则 (You Aren't Gonna Need It)
- 不写用不到的代码
- 不为未来过度设计
- MVP 思维

- 根据团队实际情况调整规范

- 渐进式改进
- 团队共识最重要
