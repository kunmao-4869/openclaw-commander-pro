# Frontend Design Skill

## 元数据

- **名称**: Frontend Design（前端设计）
- **版本**: 1.0.0
- **分类**: 编程开发
- **触发关键词**: 前端设计，UI 设计，CSS，视觉效果，界面美化
- **优先级**: 高

## 描述

前端颜值救星。内置专业设计规范，能让 AI 写出的前端代码自带生产级的视觉质量。即使不懂前端的后端程序员也能写出好看的页面。

## 设计规范

### 🎨 设计原则

1. **一致性**: 统一的配色、字体、间距
2. **层次性**: 清晰的视觉层次
3. **可用性**: 易于理解和操作
4. **响应式**: 适配各种屏幕
5. **无障碍**: 照顾特殊人群

### 🎯 配色方案

```css
/* 主色调 */
--primary-50: #eff6ff;
--primary-500: #3b82f6;
--primary-600: #2563eb;

/* 中性色 */
--gray-100: #f3f4f6;
--gray-500: #6b7280;
--gray-900: #111827;

/* 功能色 */
--success: #10b981;
--warning: #f59e0b;
--error: #ef4444;
```

### 📐 间距系统

```css
/* 基于 4px 的间距系统 */
--spacing-1: 0.25rem;  /* 4px */
--spacing-2: 0.5rem;   /* 8px */
--spacing-4: 1rem;     /* 16px */
--spacing-8: 2rem;     /* 32px */
```

## 组件库

提供常用组件的最佳实践：
- 按钮（多种状态）
- 卡片（内容容器）
- 表单（输入验证）
- 导航（响应式）
- 列表（数据展示）
- 弹窗（交互反馈）
