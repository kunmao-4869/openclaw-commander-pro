# 快速启动指南

## 🚀 立即开始

### 步骤 1: 打开项目
在 DevEco Studio 中：
```
File > Open > F:\openclaw\commander-pro\projects\HarmonyDrawGuess
```

### 步骤 2: 配置签名
1. 右键点击项目 > `Open Module Settings`
2. 选择 `Signing Configs`
3. 勾选 `Automatically generate signature`
4. 点击 `OK`

### 步骤 3: 启动模拟器
1. 打开 `Tools > Device Manager`
2. 创建一个 HarmonyOS 设备（如果没有）
3. 启动模拟器

### 步骤 4: 运行项目
1. 确保模拟器已启动
2. 点击工具栏的 `Run` 按钮（绿色三角形）
3. 等待编译和部署

### 步骤 5: 测试游戏
1. 在模拟器中打开应用
2. 输入玩家名称
3. 点击"创建房间"
4. 查看控制台日志确认功能正常

## 🛠️ 故障排除

### 问题 1: 签名失败
**解决**: 
- 确保勾选了"Automatically generate signature"
- 重启 DevEco Studio

### 问题 2: 模拟器无法启动
**解决**:
- 检查虚拟化是否开启（BIOS 设置）
- 确保有足够的内存（至少 4GB）

### 问题 3: 编译失败
**解决**:
- 检查 DevEco Studio 版本（建议 4.0+）
- 清理项目：`Build > Clean Project`
- 重新构建：`Build > Rebuild Project`

### 问题 4: 应用闪退
**解决**:
- 查看 Log 面板的错误信息
- 确保所有@State 变量正确初始化
- 检查 ArkTS 语法是否正确
