# 🚀 工作流可视化编辑器 - 使用指南

## ✨ 功能特性

### 核心功能
- 🎨 **可视化编排** - 拖拽式节点编辑，直观的工作流设计
- 🔗 **智能连接** - 贝塞尔曲线连接，美观的流程线
- 🎯 **节点类型** - 开始、技能、条件、结束四种节点
- ⚙️ **属性配置** - 实时配置节点参数和技能
- 💾 **保存加载** - JSON 格式导入导出工作流
- 🔍 **缩放平移** - 画布缩放、平移，网格对齐
- 🎭 **多节点操作** - 选择、移动、复制、删除

## 🎯 快速开始

### 1. 打开编辑器
- 点击顶部导航栏的 **"工作流"** 标签
- 进入可视化编辑器界面

### 2. 添加节点
- 点击左侧工具栏的节点类型：
  - 🟢 **开始** - 工作流起点
  - 🔵 **技能** - 执行技能操作
  - 🟡 **条件** - 条件判断分支
  - 🔴 **结束** - 工作流终点

### 3. 连接节点
1. 点击节点的 **输出连接点**（右侧圆点）
2. 拖动到目标节点的 **输入连接点**（左侧圆点）
3. 释放鼠标完成连接

### 4. 配置节点
- 点击选中节点
- 点击右上角 **设置图标** 打开属性面板
- 配置节点参数：
  - 节点名称
  - 描述信息
  - 技能选择（技能节点）
  - 参数配置
  - 条件表达式（条件节点）

### 5. 保存工作流
- 点击顶部工具栏 **"保存"** 按钮
- 工作流将保存为 JSON 文件
- 可随时通过 **"打开"** 按钮加载

## 🔧 节点类型详解

### 1. 开始节点（绿色）
- **图标**: Play
- **用途**: 工作流起点
- **配置**: 无
- **连接**: 只有输出

### 2. 技能节点（蓝色）
- **图标**: Zap
- **用途**: 执行具体技能
- **可用技能**:
  - `browser_search` - 浏览器搜索
  - `web_search` - 网络搜索
  - `analyze_search_results` - 分析搜索结果
  - `generate_project_code` - 生成项目代码
  - `review_code` - 代码审查
  - `safe_read_file` - 读取文件
  - `safe_write_file` - 写入文件
  - 等等...
- **连接**: 有输入和输出

### 3. 条件节点（黄色）
- **图标**: GitBranch
- **用途**: 条件判断
- **配置**: JavaScript 表达式
- **示例**: `result.success === true`
- **连接**: 一个输入，多个输出（真/假）

### 4. 结束节点（红色）
- **图标**: Square
- **用途**: 工作流终点
- **配置**: 无
- **连接**: 只有输入

## 💡 使用技巧

### 快捷操作
- **Ctrl + 滚轮**: 缩放画布
- **拖拽空白处**: 平移画布
- **双击连接线**: 删除连接
- **点击节点**: 选中节点
- **Ctrl + C/V**: 复制/粘贴节点（开发中）

### 最佳实践
1. **从开始节点开始**: 总是以开始节点作为起点
2. **合理命名**: 给节点起有意义的名称
3. **添加描述**: 帮助理解节点用途
4. **分组排列**: 相关节点放在一起
5. **避免交叉**: 尽量减少连接线交叉

### 性能优化
- 避免过多节点（建议 < 50 个）
- 使用条件分支简化流程
- 定期保存工作流

## 🐛 故障排除

### 问题：无法连接节点
- 确保源节点不是"结束"类型
- 确保目标节点不是"开始"类型
- 检查是否已存在相同连接

### 问题：属性面板不显示
- 确保已选中节点
- 点击右上角设置图标
- 刷新页面重试

### 问题：保存失败
- 检查工作流是否有效
- 确保至少有一个开始节点
- 确保没有孤立的节点
