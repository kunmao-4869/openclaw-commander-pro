# 快捷操作需求输入指南

## 📋 输入格式说明

### ✅ 必填项
- **项目需求描述**：详细描述你的项目需求

---

## 💡 输入格式建议

### 1. 功能描述
列出项目需要实现的主要功能

**格式**：
```
开发一个 XXX 应用，包含：
- 功能 1
- 功能 2
- 功能 3
```

### 2. 技术栈（可选）
指定使用的技术

**格式**：
```
使用 XXX 技术开发
```

### 3. 界面要求（可选）
描述界面风格或布局要求

**格式**：
```
界面要求：简洁现代 / 扁平化 / 卡通风格
```

### 4. 特殊需求（可选）
其他特殊功能或要求

**格式**：
```
特殊需求：支持离线使用 / 响应式设计
```

## 📝 完整示例

### HarmonyOS 项目示例

#### 示例 1：猜数字游戏
```
开发一个猜数字游戏，包含以下功能：
- 随机生成 1-100 的数字
- 用户输入猜测
- 提示"太大了"或"太小了"
- 记录猜测次数
- 游戏结束后显示统计信息
```

```
开发一个计算器应用，包含：

- 简洁现代的界面
```

```
开发一个待办事项管理工具，包含：
- 添加/删除/编辑任务
- 任务优先级设置
- 任务完成标记
- 数据本地存储
```

## ✅ 好的示例 vs 不好的示例

### ✅ 好的示例（详细具体）
```
开发一个猜数字游戏，包含以下功能：
- 随机生成 1-100 的数字
- 用户输入猜测
- 提示"太大了"或"太小了"
- 记录猜测次数
- 游戏结束后显示统计信息
```

### ❌ 不好的示例（太简单）
```
做一个游戏
```

### ✅ 好的示例（包含技术栈）
```
使用 ArkTS 开发一个 HarmonyOS 计算器应用，包含：
- 基本四则运算
- 科学计算功能
- 历史记录
- 深色模式
```

### ❌ 不好的示例（模糊不清）
```
做个计算器，要好用
```
