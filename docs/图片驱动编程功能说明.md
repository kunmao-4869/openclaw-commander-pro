# 🎨 图片驱动编程功能

## 📋 功能概述

自主编程引擎现在支持**图片驱动编程**模式，能够：

1. **自动扫描图片资源** - 扫描指定目录的所有图片文件
2. **智能分析图片命名** - 根据文件名推断 UI 结构和功能
3. **自动生成对应代码** - 基于图片资源生成匹配的 UI 代码
4. **自动降级处理** - 如果没有图片资源，使用自主编程模式

## 🔄 工作流程

```
开始
  ↓
扫描图片资源目录
  ↓
有图片资源？
  ├─ YES → 分析图片命名 → 图片驱动策略 → 生成代码
  └─ NO  → 使用通用策略 → 自主编程模式 → 生成代码
```

## 🛠️ 核心方法

### 1. `scanImageResources(imagePath)`
扫描并加载图片资源

**参数**:
- `imagePath`: 图片资源目录路径

**返回**:
```javascript
{
  available: true/false,
  path: '图片目录路径',
  files: ['文件 1.png', '文件 2.png', ...],
  analysis: {
    pages: { login: true, home: true, ... },
    components: [{ type: 'air_conditioner', file: '...' }, ...],
    icons: [...],
    backgrounds: [...],
    buttons: [...]
  }
}
```

### 2. `analyzeImageNames(fileNames)`
分析图片名称，推断功能

**分析规则**:
- 包含 `login`/`start` → 登录页面
- 包含 `home` → 首页
- 包含 `light` → 灯光控制页
- 包含 `curtain` → 窗帘控制页
- 包含 `service` → 服务控制页
- 包含 `icon` → 图标
- 包含 `bg`/`background` → 背景
- 包含 `btn`/`button` → 按钮
- 包含 `airconditioner` → 空调组件
- 包含 `bright`/`soft`/`read`/`warm` → 场景模式
- 包含 `toggle`/`switch` → 开关组件
- 包含 `tabs` → 底部导航

### 3. `imageDrivenStrategy(understanding, design, options)`
图片驱动的编程策略

**逻辑**:
```javascript
if (图片资源可用) {
  if (检测到智慧客房系统图片) {
    生成智慧客房系统代码
  } else {
    生成通用图片驱动应用
  }
} else {
  回退到模块化策略
}
```

## 🎯 生成的代码示例

### 图片驱动模式（有 tabs 图片）

```typescript
import router from '@ohos.router';
import { promptAction } from '@kit.ArkUI';

@Entry
@Component
struct GeneratedApp {
  @State message: string = 'SmartRoom_App';
  @State currentTab: string = 'home';

  build() {
    Column() {
      // 顶部导航
      Row() {
        Text(this.message)
          .fontSize(24)
          .fontWeight(FontWeight.Bold)
      }
      .width('100%')
      .padding(20)
      .backgroundColor('#007DFF')

      // 内容区域 - 使用图片资源
      Scroll() {
        Column() {
          // 背景图片
          Image($r('app.media.bg_hotel_full'))
            .width('100%')
            .height(200)
            .objectFit(ImageFit.Cover)
            .margin({ bottom: 20 })

          // 功能图标
          Flex({ wrap: FlexWrap.Wrap }) {
            Column() {
              Image($r('app.media.home_icon_airconditioner'))
                .width(40)
                .height(40)
              Text('airconditioner')
                .fontSize(12)
                .margin({ top: 4 })
            }
            .margin({ right: 15, bottom: 15 })
            // ... 更多图标
          }
        }
        .width('100%')
        .padding(20)
      }
      .layoutWeight(1)

      // 底部导航栏
      Row() {
        Column() {
          Image(this.currentTab === 'home' ? $r('app.media.tabs_icon_home_select') : $r('app.media.tabs_icon_home_unselect'))
            .width(24)
            .height(24)
          Text('home')
            .fontSize(12)
            .margin({ top: 4 })
            .fontColor(this.currentTab === 'home' ? '#007DFF' : '#666666')
        }
        .onClick(() => {
          this.currentTab = 'home';
        })
        // ... 更多 tab
      }
      .width('100%')
      .height(60)
      .backgroundColor('#FFFFFF')
    }
    .width('100%')
    .height('100%')
  }
}
```

## 📊 策略选择优先级

```
1. 图片驱动策略 (image_driven) ← 有图片资源时优先使用
   ↓
2. 模块化策略 (modular) ← 复杂项目/多页面
   ↓
3. 面向对象策略 (oop) ← 游戏/系统类
   ↓
4. 函数式策略 (functional) ← 数据处理类
   ↓
5. 简单策略 (simple) ← 简单脚本/工具
```
